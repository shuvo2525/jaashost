## How to Run Locally
1. Double-click \`start-server.bat\` (or run \`node server.js\` in this folder).
2. Open your browser and visit: **http://localhost:3000**

## Project Pages
- \`index.html\`: PutulHost 1:1 homepage (Hero, Notice bar, Menu dropdowns, Services, Ultra footer).
- \`basic-hosting.html\`: Basic Web Hosting packages.
- \`pro-hosting.html\`: Pro Web Hosting packages.
- \`premium-hosting.html\`: Premium Web Hosting packages.
- \`bdix-basic.html\`: BDIX Basic Web Hosting packages.
- \`bdix-premium.html\`: BDIX Premium Web Hosting packages.
- \`reseller-hosting.html\`: Reseller Web Hosting packages.
- \`vps.html\`: NVMe Cloud VPS packages.
- \`dedicated.html\`: Dedicated Server packages.
- \`email-hosting.html\`: Business Email Hosting packages.
- \`domain.html\`: Domain Search and Registration portal.
- \`cart.html\`: WHMCS 5-step order funnel (Blank domain by default).
- \`clientarea.html\`: Client Portal dashboard (Renewals, active services, cPanel SSO).
- \`invoice.html\`: Official JAAS BD Letterhead Pad Invoice with PDF download.
- \`login.html\`: Client Area Login.
- \`admin.html\`: Admin Dashboard to change prices, notice bar text, contact, and settings.
- \`server.js\`: Standalone web server and REST API.
- \`site-config.json\`: Live configuration file.
