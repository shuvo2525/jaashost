# 🚀 JAAS BD Platform - Local XAMPP Setup Guide (বাংলা ও English)

এই পুরো প্রজেক্টটি এখন একটিমাত্র ফোল্ডারে সম্পূর্ণ স্বয়ংসম্পূর্ণ (100% Self-Contained) হিসেবে সাজানো হয়েছে। আপনি যেকোনো Windows কম্পিউটারে XAMPP (Apache + MySQL) চালু করে সরাসরি রান করাতে পারবেন।

---

## 📁 প্রজেক্ট ফোল্ডার কাঠামো (Directory Structure)

## 🛠️ XAMPP-এ সেটআপ করার সহজ ধাপ (Step-by-Step Instructions)

### ধাপ ১: প্রজেক্ট ফোল্ডার XAMPP htdocs-এ রাখা
1. এই `jaasbd-website` সম্পূর্ণ ফোল্ডারটি কপি করুন।
2. আপনার কম্পিউটারের `C:\xampp\htdocs\` ডিরেক্টরিতে পেস্ট করুন।
3. সুবিধার জন্য ফোল্ডারের নাম `jaasbd` রাখতে পারেন:
   `C:\xampp\htdocs\jaasbd`

---

### ধাপ ২: XAMPP কন্ট্রোল প্যানেল চালু করা
1. **XAMPP Control Panel** ওপেন করুন।
2. **Apache** এর পাশের **Start** বাটনে ক্লিক করুন।
3. **MySQL** এর পাশের **Start** বাটনে ক্লিক করুন।
*(উভয় সার্ভিস সবুজ রঙে রানিং দেখাবে)*

---

### ধাপ ৩: ডাটাবেজ সেটআপ (২টি সহজ উপায়)

#### পদ্ধতি ক: ১-ক্লিকে অটোমেটিক সেটআপ (সবচেয়ে সহজ - Recommended)
যেকোনো ব্রাউজার (Chrome/Edge) ওপেন করে এই লিংকে যান:
👉 **[http://localhost/jaasbd/setup.php](http://localhost/jaasbd/setup.php)**

- এটি স্বয়ংক্রিয়ভাবে `jaasbd` ডাটাবেজ তৈরি করবে।
- `database.sql` থেকে সব ৮টি টেবিল (Admin, Packages, Domains, Testimonials, Clients, Services, Invoices) ইমপোর্ট করে দেবে।
- স্ক্রিনে সবুজ টিক চিহ্ন এবং সফল মেসেজ দেখাবে!

#### পদ্ধতি খ: ম্যানুয়ালি phpMyAdmin দিয়ে ইমপোর্ট (বিকল্প উপায়)
1. ব্রাউজারে যান: `http://localhost/phpmyadmin/`
2. বাম পাশের মেনু থেকে **New** এ ক্লিক করে ডাটাবেজের নাম দিন: `jaasbd` এবং **Create** বাটনে ক্লিক করুন।
3. উপরে মেনু থেকে **Import** ট্যাবে ক্লিক করুন।
4. **Choose File** বাটনে ক্লিক করে প্রজেক্টের ভেতরের `database.sql` ফাইলটি সিলেক্ট করুন।
5. নিচে নেমে **Import** / **Go** বাটনে ক্লিক করুন।

## ✨ বিশেষ সুবিধাসমূহ (Key Features Included)
1. **১০০% সিঙ্গেল ফোল্ডার ক্লিন ডিজাইন**: কোনো অপ্রয়োজনীয় স্ক্রিপ্ট বা অতিরিক্ত ইমেজ নেই।
2. **ডাটাবেজ ও অফলাইন ডুয়েল সাপোর্ট**: MySQL চালু থাকলে ডাটাবেজে ডাটা সেভ হবে, MySQL না থাকলেও ব্রাউজার স্টোরেজ দিয়ে ফুল ওয়েবসাইট নিরবচ্ছিন্নভাবে চলবে।
3. **রিয়েলটাইম প্যাকেজ ক্যালকুলেশন**:
   - শুধু হোস্টিং কিনলে হোস্টিংয়ের সঠিক যোগফল আসবে।
   - সাথে ডোমেন অ্যাড করলে স্বয়ংক্রিয়ভাবে যোগ হবে।
   - যেকোনো প্যাকেজ আন-সিলেক্ট বা পরিবর্তন করলে তাৎক্ষণিক টোটাল হিসাব আপডেট হবে।
4. **অফিসিয়াল A4 সাইজ ইনভয়েস প্যাড**: আসল প্যাডের সাথে ১০০% মিল রেখে HD ফরম্যাটে প্রিন্ট রেডি ইনভয়েস।
5. **FOSSBilling / WHMCS স্টাইল ক্লায়েন্ট এরিয়া**: একটিভ সার্ভিস, নেক্সট ডিউ ডেট, সার্ভার আইপি এবং ১-ক্লিকে cPanel-এ সরাসরি লগইন করার সুবিধা।
